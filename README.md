# agent-trading-simu-dashboard
Read-only dashboard for dean's **paper-trading simulation** (BTC/ETH/HYPE perps, 4h/1D swing). Simulation only; no real orders or exchange keys.
`index.html`/`dashboard.html` are regenerated and pushed by the sim tick (only when changed). Prices: Hyperliquid public API (Binance geo-blocked from the host).
